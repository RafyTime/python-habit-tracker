After / data changes set the pace

Today snapshot module
Own one coherent read of Profile, Due Habits, Completion progress, and XP.

Cursor keys redraw the menu from held data

ProblemThe Home module calls the read and render path for every arrow key. The snapshot seam mixes data acquisition with drawing.

SolutionDeepen the Today snapshot module so one read supplies both Today and Home. Refresh it when a habit action changes data, while the render module handles cursor movement.

locality: grouping stays in one moduleleverage: Today and Home share the readtests cover data and redraw separately

Deletion test: without this module, Profile, Due, XP, and grouping coordination would return to both Today and Home. A second adapter is not justified by the current implementation.

Top recommendation

Give Completion and XP one commit owner

Several commits split one Completion and its XP history. A single commit owner has the clearest gain in locality, leverage, and failure testing.
