# Triage vocabulary

Local tasks use these status values.

| Status | Meaning |
| --- | --- |
| `needs-triage` | Needs evaluation |
| `needs-info` | Waiting for information |
| `ready` | Specified and ready for implementation |
| `wontfix` | Will not be implemented |

For example:

```markdown
Status: ready
Blocked by: none
```

Claimed work uses `Status: claimed`; completed work uses `Status: done`. Treat legacy `resolved` as completed.
